Breach Database: the latest data breaches, tracked and sourced

This is a free, public breach intelligence platform. It is a data breach database that records which companies have suffered a breach, when it happened, who was behind it and where it was reported, with one clean record for each incident and a link back to the original source.

What the breach database covers

  • The latest data breaches worldwide, including UK and global incidents.
  • Ransomware victims named on leak sites, correlated across trackers.
  • US state attorney general breach notices, HHS breach reports and SEC filings.
  • Security press coverage attached to each breach as supporting evidence.

How it works

Sources are re-read every four hours. When several sources describe the same breach they are merged into a single record. A corroboration count then shows how many independent sources back it. Only authoritative documents create an entry, so this is a list of breached companies rather than a news feed. Built in the UK, aligned with UK GDPR and the ICO, holding breach metadata only and never the leaked personal data itself.
